# Senai-Loja-CSS

Loja Virtual — CSS Box Model e Flexbox

## Descrição

Página de loja virtual desenvolvida com HTML5 e CSS3, aplicando os conceitos da Aula 07: Box Model (content, padding, border, margin) e Flexbox para organização responsiva dos elementos.

## Tecnologias

- HTML5
- CSS3

## Conceitos aplicados (Aula 07)

- Box Model: content, padding, border, margin aplicados em 20 elementos
- Flexbox: flex-direction, justify-content, align-items, gap, flex-wrap
- Seletores CSS, classes e IDs
- Propriedades: cor, fundo, fonte, tamanho, borda, display, posicionamento

## Como executar

Abra o arquivo `index.html` em qualquer navegador moderno.
